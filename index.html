Así llegó esta página hasta ti

Un sitio estático, sin servidores que administrar, publicado automáticamente.

  1. Se escribe el códigoHTML, CSS y JavaScript guardados en un repositorio Git.
  2. El pipeline de CI/CD lo despliegaCada push a la rama principal sube los archivos al bucket de S3 e invalida la caché de CloudFront.
  3. Amazon S3 guarda los archivosEl bucket es privado y solo CloudFront puede leerlo.
  4. CloudFront lo entrega con HTTPSUn certificado de AWS Certificate Manager protege tu dominio y la red global acerca el sitio a cada visitante.
