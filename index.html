DESGLOSE TÉCNICO DE INFRAESTRUCTURA

¿Cómo está construida esta página?

Esta plataforma aplica los principios de la arquitectura Serverless y distribución perimetral multi-cloud para garantizar máxima disponibilidad y cero costo de servidores inactivos:

📦 Amazon S3 Bucket
Almacenamiento de objetos estáticos resiliente configurado con políticas de acceso público seguro y cifrado en reposo.
⚡ CloudFront CDN
Red de distribución global de contenido que sirve el sitio mediante caché en Edge Locations con certificado SSL/TLS (HTTPS).
🤖 GitHub Actions CI/CD
Pipeline automatizado que detecta cada push en el repositorio y actualiza automáticamente los assets en la nube.
☁️ GCP Storage (GCS)
Integración multi-cloud para servir objetos, assets de proyectos y el documento CV directamente desde Google Cloud Storage.
