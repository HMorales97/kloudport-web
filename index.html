Getting ready for GCP

Infraestructura Cloud & CI/CD Lab

Esta plataforma está desplegada sobre una arquitectura global optimizada. Los archivos estáticos residen de forma segura en un bucket de Amazon S3, distribuidos a nivel mundial con baja latencia mediante la CDN de Amazon CloudFront bajo cifrado seguro HTTPS/SSL. Toda la integración y el despliegue están completamente automatizados mediante un flujo de CI/CD con GitHub Actions.

AWS S3 CloudFront GitHub Actions HTTPS / SSL
